# Σπίτι Λαγκαδά

Εφαρμογή παρακολούθησης για την κατασκευή του σπιτιού στον Λαγκαδά (Πέτρος & Τζο).

- `public/index.html` — εφαρμογή: φάσεις, κόστη, πληρωμές, κάτοψη, διάταξη οικοπέδου, επιθυμίες, ερωτήσεις
- `public/3d.html` — τρισδιάστατο μοντέλο έξω και μέσα
- `netlify/functions/data.mjs` — αποθήκευση δεδομένων σε Netlify Blobs (`/api/data`)
- `netlify/functions/seed.json` — αρχικά δεδομένα, φορτώνονται μόνο την πρώτη φορά
